# Ai-assistant

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/shebaoting/ai-assistant.svg)](https://packagist.org/packages/shebaoting/ai-assistant) [![Total Downloads](https://img.shields.io/packagist/dt/shebaoting/ai-assistant.svg)](https://packagist.org/packages/shebaoting/ai-assistant)

A [Flarum](http://flarum.org) extension. A Flarum extension that uses AI for automatic replies

## Installation

Install with composer:

```sh
composer require shebaoting/ai-assistant:"*"
```

## Updating

```sh
composer update shebaoting/ai-assistant:"*"
php flarum migrate
php flarum cache:clear
```
